# Health Meal Agent

An AI agent that generates personalized, healthy meal recommendations based on individual client health data and dietary goals.

Built with **Python**, **Google Gemini**, and the **Agent Development Kit (ADK)**.

---

## What it does

The agent takes a client's health information (such as goals, dietary needs, and preferences) and uses Google's Gemini model to generate a tailored, structured meal plan — turning raw health data into practical, personalized recommendations.

---

## Tech stack

- **Python** — core agent logic
- **Google Gemini** — reasoning and meal-plan generation
- **Agent Development Kit (ADK)** — agent framework
- **Jupyter Notebook** — development and demonstration

---

## How it works

1. **Input** — client health data and dietary goals are provided to the agent.
2. **Reasoning** — Gemini processes the inputs and reasons over the client's needs.
3. **Output** — the agent returns a structured, personalized meal plan.

---

## Getting started

1. Clone the repository:
```bash
   git clone https://github.com/abdalelah0/health-meal-agent.git
```
2. Install the dependencies (see the notebook for required packages).
3. Add your Gemini API key.
4. Open the notebook and run the cells to generate a meal plan.
